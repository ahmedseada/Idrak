# Contracts kept in Idrak.Abstraction because any package can use them (CLAUDE.md: a contract any package can use, now
# or later, lives in Idrak.Abstraction), though one package uses them today. Decision 10
# (tests/Idrak.Tests/InventoryTests.cs) keeps them there; once several packages use one, its line is refused as stale,
# so the list only shrinks.
# contract | why
Idrak.Abstraction.Generation.ITokenSampler | any model that generates tokens step by step samples them the same way, whatever the tokens stand for (text, speech, images)
Idrak.Abstraction.Generation.TokenSamplers | the sampler every token-generating package takes, overridable once for all of them
Idrak.Abstraction.Retrieval.IVectorStore | embeddings of any kind (text, images, audio) are stored and searched the same way
Idrak.Abstraction.Generation.IImagePositionRule | how a vision-language family's image tokens sit on a multi-axis rotary embedding: the decoder (core) applies it, a family plug-in or an app may give its own, and a tuner or server placing tokens itself reads it
Idrak.Abstraction.Generation.ImagePositionRules | the position rules by name, beside ImageAttentionRules, overridable once for every package that places image tokens
Idrak.Abstraction.Data.IOutlineRasterizer | how glyph and shape outlines become pixels, for every package that draws text or shapes (Imaging, Nlp's synthetic pages, Vision's synthetic samples)
Idrak.Abstraction.Data.OutlineRasterizers | the outline rasterizers by name, overridable once for every package that draws outlines
Idrak.Abstraction.Data.ITextShaper | how text becomes positioned glyphs, per script, for every package that draws text (Imaging draws, Nlp's synthetic pages lay out, Vision makes text samples); a script's shaper is registered once for all of them
Idrak.Abstraction.Data.TextShapers | the shapers by script, overridable once for every package that draws text
Idrak.Abstraction.Generation.CtcDecoders | CTC decoding reads any recognizer's per-step classes the same way, whatever they stand for: speech (Audio's CTC trainer and recognizers) and text lines (OCR readers, Vision's sequence heads); a lexicon or language-model decoder is registered once for all of them
