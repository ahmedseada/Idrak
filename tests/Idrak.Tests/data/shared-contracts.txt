# Contracts kept in Idrak.Abstraction because any package can use them (CLAUDE.md: a contract any package can use, now
# or later, lives in Idrak.Abstraction), though one package uses them today. Decision 10
# (tests/Idrak.Tests/InventoryTests.cs) keeps them there; once several packages use one, its line is refused as stale,
# so the list only shrinks.
# contract | why
Idrak.Abstraction.Generation.ITokenSampler | any model that generates tokens step by step samples them the same way, whatever the tokens stand for (text, speech, images)
Idrak.Abstraction.Generation.TokenSamplers | the sampler every token-generating package takes, overridable once for all of them
Idrak.Abstraction.Retrieval.IVectorStore | embeddings of any kind (text, images, audio) are stored and searched the same way
Idrak.Abstraction.Generation.IImagePositionRule | how a vision-language family's image tokens sit on a multi-axis rotary embedding: the decoder (core) applies it, a family plug-in or an app may give its own, and a tuner or server placing tokens itself reads it
Idrak.Abstraction.Generation.ImagePositionRules | the position rules by name, beside ImageAttentionRules, overridable once for every package that places image tokens
Idrak.Abstraction.Data.IOutlineRasterizer | how glyph and shape outlines become pixels, for every package that draws text or shapes (Imaging, Text's synthetic pages, Vision's synthetic samples)
Idrak.Abstraction.Data.OutlineRasterizers | the outline rasterizers by name, overridable once for every package that draws outlines
Idrak.Abstraction.Data.ITextShaper | how text becomes positioned glyphs, per script, for every package that draws text (Imaging draws, Text's synthetic pages lay out, Vision makes text samples); a script's shaper is registered once for all of them
Idrak.Abstraction.Data.TextShapers | the shapers by script, overridable once for every package that draws text
Idrak.Abstraction.Cluster.IFailureModel | which faults a run injects (slow, dropped, lost links, partitions, late joins), for every package that runs ranks: the simulator (Idrak.Cluster) and, from C5, Idrak.Network's real transports under test, so a seeded fault plan replays the same on both
Idrak.Abstraction.Cluster.FailureModels | the failure models by name, overridable once (IDRAK_CLUSTER_FAILURES) for every package that runs ranks
Idrak.Abstraction.Generation.IAttentionPositionBias | how an attention layer adds a bias by the query's and the key's positions, for any package's attention (core's text encoders and decoders, vision and audio towers, a family plug-in's own layers); a kind is registered once (AttentionPositionBiases) for all of them
Idrak.Abstraction.Diagnostics.IProgressReporter | the live progress of any long work (a download, a load, a training run, a rollout), shown the same way by every package that reports it; made through ProgressReporters
Idrak.Abstraction.Reinforcement.IEnvironment | an environment's spaces and resources, for every package that makes or runs environments (the trainer in Idrak.Reinforcement, Idrak.Text's prompts, the plug-ins' coding and classic ones)
Idrak.Abstraction.Reinforcement.IEnvironment`2 | an episode's reset and steps, the same for every package that makes environments or runs episodes (Idrak.Reinforcement's trainer, Idrak.Text's prompts, the plug-ins)
Idrak.Abstraction.Reinforcement.IEnvironmentKind | how environments are made by name, for every package that registers one (Idrak.Text's prompts, the plug-ins) and every trainer that creates them
Idrak.Abstraction.Reinforcement.EnvironmentKinds | the environment kinds by name, overridable once for every package that registers or creates environments
Idrak.Abstraction.Reinforcement.IPolicy`2 | acting and learning, implemented by any package's policy (Idrak.Reinforcement's module policy, Idrak.Text's language-model policy) and driven by any trainer
Idrak.Abstraction.Reinforcement.IAdvantageEstimator | how rewards become advantages in a fixed order, for any package's trainer or policy, whatever acts (a network, a language model)
Idrak.Abstraction.Reinforcement.AdvantageEstimators | the estimators by name, overridable once for every package that trains a policy
Idrak.Abstraction.Reinforcement.IPolicyLoss | the algorithms' losses, computed by any package's policy (a module policy, Idrak.Text's language-model policy through its fine-tuning losses)
Idrak.Abstraction.Reinforcement.PolicyLosses | the policy losses by name, overridable once for every package whose policy trains with them
