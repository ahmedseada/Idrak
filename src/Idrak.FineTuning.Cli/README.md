# idrak-tune

idrak-tune: fine-tune pretrained language models (LoRA / QLoRA) on any dataset idrak-data reads, evaluate them, chat with them and export them; one tool for every fine-tuning job.

## Install

```bash
dotnet tool install -g Idrak.FineTuning.Cli
idrak-tune --help
```

Update with `dotnet tool update -g Idrak.FineTuning.Cli`.

Part of [Idrak](https://www.nuget.org/packages/Idrak), a self-contained deep-learning library for .NET.
