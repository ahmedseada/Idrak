# Idrak.Onnx

ONNX export for Idrak models (no dependencies): networks become .onnx files that ONNX Runtime, TensorRT, OpenVINO, DirectML and other runtimes can run.

## Install

```bash
dotnet add package Idrak.Onnx
```

Part of [Idrak](https://www.nuget.org/packages/Idrak), a self-contained deep-learning library for .NET.
