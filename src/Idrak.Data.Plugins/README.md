# Idrak.Data.Plugins

**Reserved, not implemented.** This package keeps the name `Idrak.Data.Plugins` for document formats as plug-ins on
Idrak.Data, starting with Office (Word, Excel, PowerPoint) on the document contract. It holds no types yet; installing
it adds nothing to an app beyond its dependency on `Idrak.Data`.
