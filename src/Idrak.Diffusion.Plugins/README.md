# Idrak.Diffusion.Plugins

**Reserved, not implemented.** This package keeps the name `Idrak.Diffusion.Plugins` for the diffusion model families as
plug-ins on Idrak.Diffusion, one namespace per family, as Idrak.Text.Plugins and Idrak.Vision.Plugins hold theirs. It
holds no types yet; installing it adds nothing to an app beyond its dependency on `Idrak.Diffusion`.

Where it stands: planned in
[plans/opened/20-diffusion.md](https://github.com/ahmedseada/Idrak/blob/main/plans/opened/20-diffusion.md). The packages
that work today are listed in the library's [README](https://github.com/ahmedseada/Idrak#packages).
