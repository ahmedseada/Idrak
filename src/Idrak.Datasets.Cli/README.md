# idrak-data

idrak-data: inspect, count, download and assemble training datasets from Hugging Face, GitHub, Kaggle, Zenodo, URLs and local files (JSON Lines, JSON, CSV, text, code, Parquet) into JSON Lines any tool can read.

## Install

```bash
dotnet tool install -g Idrak.Datasets.Cli
idrak-data --help
```

Update with `dotnet tool update -g Idrak.Datasets.Cli`.

Part of [Idrak](https://www.nuget.org/packages/Idrak), a self-contained deep-learning library for .NET.
