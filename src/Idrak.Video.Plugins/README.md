# Idrak.Video.Plugins

**Reserved, not implemented.** This package keeps the name `Idrak.Video.Plugins` for the video model families as
plug-ins on Idrak.Video, one namespace per family, as Idrak.Text.Plugins and Idrak.Vision.Plugins hold theirs. It holds
no types yet; installing it adds nothing to an app beyond its dependency on `Idrak.Video`.

Where it stands: planned, no plan written yet. The packages that work today are listed in the library's
[README](https://github.com/ahmedseada/Idrak#packages).
