# Idrak.Pretrained

Pretrained language models for Idrak (no dependencies): models by Hugging Face id (downloaded and cached) or folder, safetensors weights, Hugging Face configurations mapped to DecoderSpec through an extensible architecture registry, BPE tokenizers from tokenizer.json, and chat templates.

## Install

```bash
dotnet add package Idrak.Pretrained
```

Part of [Idrak](https://www.nuget.org/packages/Idrak), a self-contained deep-learning library for .NET.
