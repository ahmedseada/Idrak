# Idrak.Mcp

Model Context Protocol for Idrak: use the tools of MCP servers in conversations and the inference engine, and serve Idrak tools to MCP clients.

## Install

```bash
dotnet add package Idrak.Mcp
```

Part of [Idrak](https://www.nuget.org/packages/Idrak), a self-contained deep-learning library for .NET.
