# Idrak.Video

**Reserved, not implemented.** This package keeps the name `Idrak.Video` for video in and out: decoding and encoding
frames, frame sampling and video datasets, with the contracts the video model families plug into. It holds no types yet;
installing it adds nothing to an app beyond its dependency on `Idrak.Abstraction`.

Where it stands: planned, no plan written yet. The packages that work today are listed in the library's
[README](https://github.com/ahmedseada/Idrak#packages).
