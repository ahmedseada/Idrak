# Idrak.HarfBuzz

**Reserved, not implemented.** This package keeps the name `Idrak.HarfBuzz` for HarfBuzz as a second text shaper beside
the library's own, registered by name, for checking fonts against it and for apps that want it to shape. It holds no
types yet; installing it adds nothing to an app beyond its dependency on `Idrak.Imaging`.

Where it stands: planned in
[plans/opened/plugins/1-harfbuzz.md](https://github.com/ahmedseada/Idrak/blob/main/plans/opened/plugins/1-harfbuzz.md).
The packages that work today are listed in the library's [README](https://github.com/ahmedseada/Idrak#packages).
