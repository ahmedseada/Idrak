# Idrak.Diffusion

**Reserved, not implemented.** This package keeps the name `Idrak.Diffusion` for image and audio generation by
denoising: UNet and DiT denoisers, noise schedules and samplers, latent codecs (VAE) and text conditioning, with the
contracts the diffusion families plug into. It holds no types yet; installing it adds nothing to an app beyond its
dependency on `Idrak.Abstraction`.

Where it stands: planned in
[plans/opened/20-diffusion.md](https://github.com/ahmedseada/Idrak/blob/main/plans/opened/20-diffusion.md). The packages
that work today are listed in the library's [README](https://github.com/ahmedseada/Idrak#packages).
