# Idrak.CoreML

**Reserved, not implemented.** This package keeps the name `Idrak.CoreML` for Apple's Neural Engine through Core ML: an
exported model converted to Core ML and run behind the library's serving contracts. It holds no types yet; installing it
adds nothing to an app beyond its dependency on `Idrak.Abstraction`.

Where it stands: planned in
[plans/opened/5-apple.md](https://github.com/ahmedseada/Idrak/blob/main/plans/opened/5-apple.md), step 5. The packages
that work today are listed in the library's [README](https://github.com/ahmedseada/Idrak#packages).
